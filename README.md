Walker Jackson The Game:
Walker Jackson is an endless 2d runner game based on a ghost named ghosty
who runs to infinity, collects coins, avoids obstacles by using shields
I made this game on unity because it was way easier to use than godot
why I made this game?
because I wanna grab an framework laptop and some hardware grants and in the future im gonna work on more games.
I learned some advanced c# while building this game and I really loved it.
this project doesn't has a lot of features because it's my first one and I wanted to built something that was easy
Controls of the game:
click space to jump to dodge obstacles 
collect shields to save your lives if you get hit by an obstacle.
break your own high scores!
how to play:
this game is the web version so you can just go and play it on itch without downloading it.
this is my first game that ive ever built and I hope that you'll like it
